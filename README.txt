# 🌟 Overview

Modern oil wells require continuous optimization to maximize production while ensuring operational safety.

This project introduces an **Autonomous Production Choke Controller** that combines **Machine Learning**, **Predictive Analytics**, and **Safety-Based Optimization** to automatically recommend the best choke valve opening.

Instead of relying on manual adjustments, the controller predicts production behavior for multiple choke settings and intelligently selects the safest option that delivers maximum oil production.

---

# 🎯 Problem Statement

Develop an intelligent controller capable of:

- 📈 Maximizing oil production
- 🛡️ Maintaining safe operating pressures
- 🤖 Automating choke valve decisions
- ⚡ Responding intelligently to changing operating conditions

# 📊 Dataset

The simulated dataset contains operational parameters of a naturally flowing oil well.

### Variables

| Variable | Description |
|----------|-------------|
| Time | Simulation Time |
| Choke (%) | Choke Valve Opening |
| Oil Rate | Oil Production (bbl/hr) |
| WHP | Wellhead Pressure |
| FLP | Flowline Pressure |
| BHP | Bottom Hole Pressure |
